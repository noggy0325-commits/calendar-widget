설치·사용 안내

처음 한 번만 설치와 구글 로그인을 하면, 그다음부터는 바탕화면에서 바로 씁니다.

설치 파일 내려받기 (Windows, 약 70MB)

1. 설치

  1. 위 버튼으로 받은 CalendarWidget.App-win-Setup.exe를 실행합니다. 관리자 권한은 필요 없습니다.
  2. 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다. 사내 배포용이라 서명 인증서를 붙이지 않아서 나오는 안내입니다.
  3. 설치가 끝나면 위젯이 바탕화면 오른쪽 위에 나타납니다. 다음부터는 Windows를 켤 때 자동으로 실행됩니다.

2. 구글 로그인 (처음 한 번)

  1. 위젯 오른쪽 위의 "구글 로그인"을 누르면 브라우저가 열립니다.
  2. 쓰는 구글 계정을 고릅니다.
  3. "Google에서 이 앱을 확인하지 않음" 화면이 나오면 고급 → CalendarWidget(으)로 이동을 누릅니다. 사내용이라 구글 심사를 받지 않아서 나오는 화면입니다.
  4. 권한 화면에서 체크박스를 모두 체크하고 계속을 누릅니다. 하나라도 빠지면 다시 로그인해야 합니다.
  5. 브라우저에 "로그인 완료"가 보이면 창을 닫습니다. 위젯에 일정이 나타납니다.

한 번 로그인하면 다시 로그인할 필요가 없습니다. 위젯 설정에서 로그아웃하거나 구글 계정에서 권한을 해제한 경우에만 다시 로그인합니다.

3. 위젯 위쪽 버튼

버튼하는 일
◀ ▶이전·다음 달(또는 주)로 이동. 날짜 칸 위에서 마우스 휠을 굴려도 됩니다.
오늘어디를 보고 있든 오늘로 돌아옵니다.
조회조건 ▾보여줄 캘린더를 체크로 고릅니다. 아래 "내가 등록한 일정만 보기"를 체크한 캘린더는 다른 사람이 등록한 일정을 숨깁니다(근태처럼 여럿이 함께 쓰는 캘린더에 유용). 필터가 걸려 있으면 버튼이 "조회조건 2/4 · 내 일정"처럼 굵게 바뀝니다.
⬆ 업데이트새 버전이 있을 때만 나타납니다. 누르면 위젯이 새 버전으로 다시 켜집니다.
⟳ 동기화위젯에서 쓴 메모를 구글로 보내고, 구글의 최신 일정을 가져옵니다. 버튼을 누를 때만 통신합니다.
🔒 자물쇠위치·크기 고정. 풀면 제목줄을 끌어 옮기고, 일반 창처럼 가장자리나 모서리 어디든 끌어서 크기를 바꿀 수 있습니다. 잠금을 푼 동안에는 위젯이 다른 창 위에 떠서 다른 모니터로 옮길 때도 가려지지 않습니다. 다 되면 다시 잠그면 바탕화면으로 돌아갑니다.
⚙ 설정배경색·글자 크기·주말·표시할 캘린더 등 설정 창을 엽니다(위젯 우클릭 → 설정과 같음).

4. 메모(일정) 쓰기

  1. 날짜 칸을 두 번 클릭하면 그날 메모창이 열립니다.
  2. 날짜 아래의 캘린더 칩(색·이름·줄 수)을 눌러 어느 캘린더에 쓸지 고릅니다. 고른 캘린더의 줄만 편집되고, 다른 캘린더의 줄은 아래에 회색으로 보입니다. 마지막에 고른 캘린더가 다음부터 기본값이 됩니다.
  3. 한 줄에 하나씩 씁니다. 한 줄이 그날의 일정 하나가 됩니다. 시간은 "회의(14시)"처럼 글로 씁니다. Enter로 다음 줄.
  4. ✓ 버튼, 메모창 밖 클릭, Ctrl+Enter 중 하나로 저장. Esc는 저장하지 않고 닫기.
하고 싶은 것방법
완료 표시(취소선)줄을 고르고(여러 줄 드래그 가능) Ctrl+D 또는 완료 버튼. 한 번 더 누르면 취소. 위젯에서 일정을 우클릭 → 완료 표시도 됩니다. 완료한 일정은 그날 맨 아래로 내려갑니다.
고치기·지우기메모창에서 그 줄의 글을 고치거나 지우고 저장합니다.
복사·붙여넣기복사하면 글자만 복사됩니다. 여러 줄을 붙여넣으면 줄마다 일정 하나가 됩니다.

저장한 메모는 위젯에 바로 보이지만, ⏳ 표시가 붙어 있는 동안은 아직 구글에 보내지 않은 상태입니다. 동기화를 누르면 구글 캘린더에 반영됩니다.

다른 사람이 등록한 일정은 고칠 수 없습니다. 공유 캘린더에서 다른 사람이 넣은 일정은 메모창 아래 "다른 사람이 등록 (수정 불가)"에 등록자와 함께 보이기만 하고, 위젯에서 수정·삭제·완료 표시를 할 수 없습니다.

5. 설정 (⚙ 버튼 또는 위젯 우클릭 → 설정)

  • 배경색·불투명도·글자 크기
  • 주말(토·일) 표시, 이번 주부터 보기(오늘이 든 주를 맨 위에)
  • 위젯에 표시할 캘린더, Windows 시작 시 자동 실행, 구글 로그아웃

여러 모니터를 쓰는 경우에도 위젯을 둔 모니터와 자리가 그대로 기억됩니다.

6. 작업 표시줄 아이콘

  • 파란 달력: 정상 실행 중. 주황 달력: 확인이 필요한 상태(마우스를 올리면 이유가 보입니다).
  • 아이콘을 누르면 메뉴가 열립니다: 위젯 표시/숨기기, 지금 동기화, 설정, 종료.

7. 업데이트

동기화 버튼을 누를 때 새 버전이 있으면 자동으로 받아 둡니다. 그러면 위젯 위쪽에 파란 ⬆ 업데이트 버튼이 나타납니다. 누르면 바로 적용되고, 그냥 두면 다음에 위젯을 켤 때 적용됩니다.

8. 자주 묻는 질문

"Google에서 이 앱을 확인하지 않음" 경고가 나오는데 괜찮나요?
네. 사내에서만 쓰는 프로그램이라 구글의 공개 앱 심사를 받지 않아서 나오는 안내입니다. 위젯은 내 캘린더 목록과 일정만 다루고, 메일·드라이브 등 다른 데이터에는 접근하지 않습니다.
다른 사람이 내 일정을 볼 수 있나요?
아니요. 각자 자기 구글 계정으로 로그인하고, 일정은 자기 구글 캘린더와 자기 PC에만 있습니다. 위젯은 별도 서버로 아무것도 보내지 않습니다. 원래 구글 캘린더에서 공유한 캘린더만 함께 보입니다.
인터넷이 끊겨도 쓸 수 있나요?
마지막으로 동기화한 일정은 그대로 보이고 메모도 쓸 수 있습니다(⏳ 표시). 인터넷이 다시 되면 동기화를 눌러 구글에 보내면 됩니다.
컴퓨터가 느려지지 않나요?
동기화 버튼을 누를 때만 통신하고, 평소에는 CPU를 쓰지 않습니다. 메모리도 작업 관리자 기준 수십 MB 수준입니다.
여러 PC에서 쓸 수 있나요?
네. PC마다 설치하고 같은 구글 계정으로 로그인하면 됩니다. 한 PC에서 쓴 메모는 동기화하면 다른 PC에서도 동기화할 때 보입니다.

9. 문제가 생기면

  1. 작업 표시줄 아이콘 → 고급 → 진단 정보 복사를 누릅니다.
  2. 복사된 내용을 위젯 오른쪽 아래에 표시된 담당자에게 사내 메신저로 붙여 넣어 보내 주세요. 일정 내용이나 비밀번호는 들어 있지 않습니다.

10. 제거

Windows 설정 → 앱 → 설치된 앱에서 CalendarWidget을 제거합니다. 로그인 정보와 저장된 일정까지 지우려면, 제거 전에 위젯 설정에서 로그아웃을 먼저 눌러 주세요.
