← CalendarWidget

개인정보처리방침

시행일: 2026년 10월 14일

CalendarWidget(이하 "앱")은 사용자의 구글 캘린더를 Windows 바탕화면에 보여주고, 사용자가 위젯에서 작성한 메모를 사용자의 구글 캘린더에 저장하는 Windows 프로그램입니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 앱이 접근하는 정보

사용자가 구글 계정으로 로그인하고 권한을 허용하면, 앱은 다음 정보에 접근합니다.

구글 권한접근하는 정보쓰는 곳
calendar.calendarlist.readonly 캘린더 목록(이름, 색상, 접근 권한) 위젯에 표시할 캘린더를 고르고, 일정을 캘린더 색으로 보여주기 위해
calendar.events 일정의 제목, 날짜·시간, 장소, 설명, 색상, 생성 시각 일정을 위젯에 보여주고, 사용자가 위젯에서 쓰거나 고치거나 지운 메모를 구글 캘린더에 반영하기 위해

앱은 기본 캘린더의 ID(구글 계정 이메일 주소)를 연결된 계정을 표시하는 데에만 씁니다. 앱은 연락처, Gmail, 드라이브 등 캘린더 이외의 구글 데이터에 접근하지 않습니다.

2. 정보를 저장하는 곳

  • 사용자의 PC에만 저장합니다. 저장 위치는 %LOCALAPPDATA%\CalendarWidget 폴더입니다.
  • 가져온 일정은 다음 실행 때 인터넷 없이 바로 보여주기 위해 이 폴더에 저장합니다.
  • 위젯에서 쓴 메모 중 아직 구글에 보내지 않은 내용도 이 폴더에 잠시 보관합니다.
  • 구글 로그인 정보(갱신 토큰)는 Windows 데이터 보호 기능(DPAPI)으로 암호화해 저장합니다. 같은 PC의 같은 Windows 계정에서만 풀 수 있습니다.

3. 정보를 보내는 곳

  • 앱은 구글 서버(Google Calendar API, Google 인증 서버)와만 직접 통신합니다.
  • 개발자나 다른 제3자에게 일정, 계정 정보, 사용 기록을 보내지 않습니다. 앱 개발자는 별도의 서버를 운영하지 않습니다.
  • 광고, 분석 도구, 사용 통계 수집 기능이 없습니다.
  • 앱은 사용자가 동기화 버튼을 누를 때에만 구글과 통신합니다.

4. 구글 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구 사항을 준수합니다. 구글 사용자 데이터를 광고에 쓰거나 판매하지 않으며, 위에 적은 기능을 제공하는 데에만 사용합니다.

5. 보관 기간과 삭제

  • 앱 설정 창에서 로그아웃하면 구글 접근 권한을 해제하고, PC에 저장된 로그인 정보와 일정 캐시, 보내지 않은 메모를 지웁니다.
  • 앱을 제거한 뒤 %LOCALAPPDATA%\CalendarWidget 폴더를 지우면 PC에 남은 정보가 모두 삭제됩니다.
  • 구글 계정의 서드 파티 액세스 관리 화면에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다.
  • 구글 캘린더에 저장된 일정은 구글 계정에 남으며, 구글 캘린더에서 직접 관리할 수 있습니다.
